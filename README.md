# Лабораторная работа: метод k-средних

Реализация алгоритма кластеризации на чистом Python: без NumPy, scikit-learn
и других внешних зависимостей. Требуется **Python 3.10+**.

## Файлы

- `kmeans.py` — алгоритм, генератор случайных данных и демонстрация.
- `test_kmeans.py` — автоматические тесты на стандартном `unittest`.
- `AGENTS.md` — правила работы с репозиторием.

## Запуск

Из папки проекта:

```bash
python kmeans.py
python -m unittest discover -v
```

Первая команда генерирует 150 двумерных точек вокруг трёх заданных центров,
кластеризует их и выводит найденные центры, размеры групп, значение целевой
функции и число итераций. Вторая запускает тесты.

## Как работает алгоритм

На вход подаются `n` точек одинаковой размерности `d` и число кластеров `k`.

1. Случайно выбрать `k` строк данных в качестве начальных центров.
2. Отнести каждую точку к ближайшему центру по евклидову расстоянию.
3. Для каждой группы вычислить новый центр — среднее арифметическое координат.
4. Повторять шаги 2–3, пока смещение каждого центра не станет меньше или равно
   `tol` либо не будет выполнено `max_iter` итераций.
5. Пересчитать метки для итоговых центров и вычислить `inertia`.

Алгоритм минимизирует сумму квадратов расстояний точек до центров своих групп:

```text
J = Σ ||xᵢ − μ[labelᵢ]||²
```

Здесь `xᵢ` — точка, `μ` — центр, `labelᵢ` — номер её кластера.
Квадрат расстояния позволяет сравнивать близость без извлечения корня.
Для вычисления смещения центра корень нужен, поскольку `tol` задан в единицах
координат.

Результат зависит от начальных центров. Поэтому выполняется `n_init` запусков,
а возвращается вариант с наименьшим `J`. Глобальный минимум не гарантируется.
Время работы: `O(n_init × max_iter × n × k × d)` в худшем случае;
дополнительная память: `O(n × d + k × d)`.

## Использование из кода

```python
from kmeans import kmeans, make_blobs

points, true_labels = make_blobs(
    centers=[(-5, -5), (0, 5), (5, -5)],
    samples_per_cluster=50,
    std=0.5,
    seed=42,
)
result = kmeans(points, k=3, seed=42)

print(result.centers)    # Координаты найденных центров
print(result.labels)     # Номер кластера каждой входной точки
print(result.inertia)    # Сумма квадратов расстояний
print(result.n_iter)     # Число итераций выбранного запуска
print(result.converged)  # Выполнено ли условие остановки по tol
```

`make_blobs` добавляет к каждой координате заданного центра независимый
нормальный шум со стандартным отклонением `std`, затем перемешивает точки
вместе с исходными метками. `std=0` создаёт точные копии центров.
Исходные метки нужны для проверки качества; алгоритм их не получает.

Параметры `kmeans`:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `data` | обязательный | Непустая коллекция точек, включая генераторы |
| `k` | обязательный | Число центров, от 1 до числа точек |
| `max_iter` | `300` | Максимум итераций одного запуска |
| `tol` | `1e-4` | Допустимое смещение каждого центра; `0` требует неподвижности |
| `n_init` | `10` | Число запусков со случайной инициализацией |
| `seed` | `None` | Целое число для воспроизводимости, например `42` |

Локальный генератор случайных чисел не меняет глобальное состояние `random`.
Входные данные не изменяются; результат содержит неизменяемые кортежи.

## Граничные случаи и ограничения

- Пустой кластер сохраняет прежний центр. При одинаковых расстояниях выбирается
  центр с меньшим индексом. Поэтому занятых групп может оказаться меньше `k`,
  особенно при повторяющихся точках.
- Номера кластеров условны: правильные разбиения могут иметь разные номера.
- После остановки метки всегда соответствуют ближайшим итоговым центрам.
  При остановке по лимиту или большому `tol` центры могут ещё не быть средними
  точек с итоговыми метками; `converged` означает выполнение условия по `tol`.
- Пустые данные, разная размерность, нечисловые координаты, `NaN`, бесконечности
  и некорректные параметры отвергаются с `ValueError`. Слишком большие числа,
  приводящие к переполнению расстояний или их суммы, также отвергаются.
- Перед анализом реальных данных признаки с разными единицами измерения обычно
  масштабируют. Алгоритм чувствителен к выбросам и лучше подходит для компактных
  групп; число `k` задаёт пользователь.

## Тестирование

В `test_kmeans.py` находятся 39 тестовых методов, часть с несколькими сценариями
через `subTest`. Они проверяют:

- известные центры, разбиение и целевую функцию на небольших примерах;
- одну точку, `k=1`, `k=n`, повторы, пустые кластеры и разные размерности;
- остановку по `tol` и лимиту, соответствие итоговых меток ближайшим центрам;
- отсутствие ухудшения целевой функции при увеличении числа запусков и итераций
  на фиксированных данных;
- восстановление разделённых случайных групп на десяти seed;
- изменение центров и целевой функции при переносе и масштабировании;
- генератор данных: количество, размерность, метки, среднее, разброс и seed;
- неизменность входных данных и глобального состояния `random`;
- ошибки входных данных, параметров и числовые переполнения.
- запуск демонстрации и вывод результата.

Случайные тесты используют фиксированные seed, чтобы ошибки воспроизводились.
Тесты проверяют поведение и математические свойства; прохождение всех тестов
не является доказательством корректности для любых входных данных.
